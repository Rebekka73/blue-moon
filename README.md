# PocketSmart AI - Your Smart Budget & Recommendation Assistant

## Project Type
AI Augmented Backend Application

## Overview
PocketSmart AI is a smart finance assistant that tracks expenses, manages budgets, and gives AI-powered personalized recommendations to save money. Built for students and young professionals.

## Features
- Expense Tracking via Text / Voice / Bill Image (OCR)
- Auto-Categorization (Food, Travel, Shopping, Bills)
- AI Budget Engine with alerts & savings prediction
- Recommendation Chatbot - "Can I afford this?"
- Dashboard with Charts & Budget Health Score

## Tech Stack
- Backend: Python FastAPI
- AI: Gemini API / OpenAI API
- OCR: Tesseract
- Database: MongoDB / Firestore
- Frontend: Flutter (planned)

## How It Works
User Input -> FastAPI -> AI Engine + OCR -> Budget Logic -> Database -> Recommendations

## Future Scope
- UPI Auto-Sync
- Chennai Local Deals Integration
- Subscription Tracker
